# Ontology snapshot

CSV exports of an ontology vocabulary related to active inference and the free energy principle.

## Files

- `Ontology_TermsOnly.csv` — a one-column `Term` list containing 408 non-empty terms in the checked-in snapshot.
- `Ontology _ Definitions, Examples, Connections view.csv` — a view with `List`, `Term`, `Proposed Definition 1`, and `Proposed Definition 2` columns.

The files are snapshots rather than a validated ontology release. Definitions are proposed text in the source export; preserve that status when reusing them. The directory was historically named `Ontology snapshot` (with a space) and migrated to `Ontology_Snapshot` on 2026-08-02.

## Canonical ontology home

This directory is a frozen December 2022 export. The ontology is published from
[`Active_Inference_Ontology`](https://github.com/ActiveInferenceInstitute/Active_Inference_Ontology),
whose current content release is v5 (May 25, 2023, 429 terms) with stable
identities and typed relations. 402 of the 408 terms here also appear in that
release; the canonical repository additionally archives the
[December 12, 2022 snapshot](https://github.com/ActiveInferenceInstitute/Active_Inference_Ontology/tree/main/Archived%20versions/v4%20(12-12-2022%20snapshot))
of the same export and publishes the
[GNN vocabulary bridge](https://github.com/ActiveInferenceInstitute/Active_Inference_Ontology/tree/main/GNN)
for `ActInfOntologyAnnotation` labels. Use the canonical repository for current
terms and identifiers.
