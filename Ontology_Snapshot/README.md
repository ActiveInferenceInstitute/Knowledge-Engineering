# Ontology snapshot

CSV exports of an ontology vocabulary related to active inference and the free energy principle.

## Files

- `Ontology_TermsOnly.csv` — a one-column `Term` list containing 408 non-empty terms in the checked-in snapshot.
- `Ontology _ Definitions, Examples, Connections view.csv` — a view with `List`, `Term`, `Proposed Definition 1`, and `Proposed Definition 2` columns.

The files are snapshots rather than a validated ontology release. Definitions are proposed text in the source export; preserve that status when reusing them. The directory was historically named `Ontology snapshot` (with a space) and migrated to `Ontology_Snapshot` on 2026-08-02.
