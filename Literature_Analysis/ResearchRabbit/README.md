# ResearchRabbit

A ResearchRabbit literature-map export and related DOI mapping captured in December 2022.

## Files

- `daniel_friedman_raw_data.json` — ResearchRabbit graph JSON with `nodes` and `edges`; the snapshot contains 250 nodes.
- `ID_DOI_3_28_2022.xlsx` — spreadsheet mapping `COGSEC_ID` values to DOI values.
- `ResearchRabbit_HALF22_image.png` — exported graph image.
- `ResearchRabbit-20221212T224443Z-001.zip` — original bundle containing the image, spreadsheet, and JSON export.

The ZIP is retained as a source bundle and duplicates the three extracted files. The JSON and spreadsheet are dated snapshots; no script in this repository regenerates them.
