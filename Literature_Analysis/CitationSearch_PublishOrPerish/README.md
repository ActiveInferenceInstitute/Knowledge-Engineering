# CitationSearch_PublishOrPerish

A Publish-or-Perish export of Google Scholar results for queries concerning active inference, the free energy principle, or Karl Friston.

## Files

The same export is preserved in three formats:

- TSV — easiest to inspect as plain text and the largest export, with 2,894 data rows.
- ODS — OpenDocument spreadsheet.
- XLSX — Microsoft Excel spreadsheet.

The TSV header records `Cites`, `Authors`, `Title`, `Year`, `Source`, `Publisher`, `ArticleURL`, `CitesURL`, `GSRank`, `QueryDate`, `Type`, and `DOI` fields. The export includes the source query date in its `QueryDate` column where supplied by Publish-or-Perish.

These are historical Google Scholar results and should not be interpreted as current citation counts. Google Scholar, publishers, and linked services control the underlying records and URLs.
